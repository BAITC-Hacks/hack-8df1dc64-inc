# Почасовой прогресс

Заполняется автоматически агентом после каждой значимой задачи (см. `CLAUDE.md`/`AGENTS.md`
п.9). Это не только внутренняя дисциплина — это прямое доказательство «подтверждённого
промежуточного результата» за отчётный час, требуемого Положением (отсутствие такого
результата за любой час — основание для дисквалификации). Пишем простыми словами: что сделано
и как это работает — не техническим жаргоном ради жаргона, а так, чтобы это можно было
зачитать судье на вопрос «а что тут вообще происходит».

Если участник в этот час сменил модуль (см. `docs/handover-protocol.md`) — отметить это в
колонке «Что сделано» (например: «Переключился с Data на Backend, см. task-board»).
