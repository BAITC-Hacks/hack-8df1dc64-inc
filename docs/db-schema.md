# Схема данных

Источник истины по структуре данных, которыми оперируют `/data`, `/backend` и (косвенно, через
API) `/ui`. Меняется только в этом файле первым шагом, затем — в коде `/data` и там, где
`/backend` и `/ui` на неё опираются.
