## Финальный шаг — проверка воспроизводимости (за 20–30 мин до дедлайна)

Технические эксперты должны суметь самостоятельно развернуть и запустить проект по README.
Несоответствие этому — риск недопуска к дальнейшему отбору. Обязательно, без исключений:

1. Клонировать репозиторий в чистую папку (`git clone` в новую директорию, не использовать
   текущую рабочую с уже настроенным окружением)
2. Пройти README от начала до конца буквально, как посторонний человек
3. Убедиться, что основной сценарий из README воспроизводится
4. Если что-то не работает — чинить сейчас, «дополнительные пояснения и исправления» после
   сдачи не принимаются
5. Проверить, что README содержит: описание решения и назначение, описание архитектуры,
   используемые технологии, инструкции по установке, инструкции по запуску, зависимости,
   параметры окружения, порядок проверки основного сценария — по чек-листу в самом README
6. Проверить демо/тестовый доступ к внешним API (см. `docs/resources-needed.md`) — эксперт не
   должен нуждаться в личном аккаунте участника
