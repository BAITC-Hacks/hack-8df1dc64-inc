## Что именно загружено локально

На этом шаге загружены **только Markdown-файлы**, как уточнил пользователь. Python-код
backend/data и их рабочие тесты остаются в соответствующих удалённых ветках.
Локальные `backend/test.sh` и `data/test.sh` — старые неотслеживаемые файлы шаблона;
их наличие не означает, что модули загружены или работают. Поэтому команды из импортированных
README этих модулей нельзя считать проверенными в текущей рабочей папке.

Новые исполняемые тесты для изменения документации не требуются: проверены перечень путей,
хеши трёх импортов, различия общих документов и отсутствие изменений исходного кода.
Ранее выполненные тесты UI относятся к интерфейсу, а не к готовности всего проекта.

## Порядок закрытия пробелов

1. Backend и UI согласовывают HTTP-контракт и формат почасового результата до подключения UI.
2. Data уточняет исходный датасет, его время/мощность и историческую доступность погодного архива.
3. Команда заполняет архитектуру, конкретный план и общую инструкцию запуска по фактической реализации.
4. Имеющиеся ТЗ, критерии и роли переносятся в предусмотренные документы без выдумывания неизвестных данных.
