# Общие документы и рабочие ветки

Репозиторий: https://github.com/BAITC-Hacks/hack-8df1dc64-inc

Общая версия `AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/` и инфраструктуры `.claude/`
публикуется в `main`. Код модулей развивается в `backend`, `data` и `ui`.
Согласованные интерфейсы — только в `docs/api-contract.md` и `docs/db-schema.md`.

## Получить общие документы

Из корня своего клона, находясь в своей рабочей ветке, после коммита локальной работы:

```bash
git fetch origin
git merge origin/main
```

Это добавляет изменения общей ветки в рабочую. `git pull` без указания ветки обновляет
только upstream текущей ветки и сам по себе не переносит новые документы из `main`.
Если Git сообщает конфликт, покажите различия команде до выбора версии; записи о работе
каждого участника нужно сохранить.
