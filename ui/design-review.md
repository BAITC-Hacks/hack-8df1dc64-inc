Страницы условий и приватности описывают текущую локальную демонстрацию. Они не заявляют
готовность правил будущего публичного сервиса: оператор, контакты и обработка данных
хостингом пока не определены. Эти сведения нужны перед публичным запуском.

## Что нужно от команды для работающего прогноза

- Backend: HTTP API запуска, получения результата и ошибок по согласованному контракту.
- Data: готовая история и архивные погодные прогнозы; уточнённый смысл временных меток и мощности.
- Вместе: подключение модулей, проверка полного сценария и общая инструкция запуска.

## Проверка

20 тестов прошли: существующие сценарии формы и хранения, реальные HTTP-ответы новых
страниц/модулей, успешная и неуспешная инициализация, проверка перечисленных запретов
в исходном CSS и публичном HTML. Для управления skeleton нет имитации backend.
Ограничение проверки: тесты загрузки используют объекты состояния элементов, а не браузерный DOM.
