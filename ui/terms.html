Условия использования

Локальная демонстрационная версия · 23 сентября 2026

Назначение

Vento создаётся командой проекта на HackAlem для демонстрации почасового прогнозирования выработки ветроэлектростанции. Эта версия воспроизводит исторические запуски: выберите дату, час UTC, горизонт и турбины.

Доступные функции

Можно запускать расчёт по архивной погоде, получать анализ OpenAI, просматривать почасовой график и таблицу, скачивать CSV и повторять расчёт после обновления погоды. Мощность нормализована в шкале 0–1; точность на февральских фактических данных пока не проверена.

Применение

Используйте эту версию для ознакомления с интерфейсом и проверки сценария. Она не предназначена для управления оборудованием или принятия производственных решений. Выбранные параметры сами по себе не являются прогнозом выработки.

Сохранение настроек

Настройки хранятся в вашем браузере. Их можно удалить кнопкой «Сбросить параметры» на рабочем экране. Условия хранения подробно описаны на странице конфиденциальности.

Изменения версии

Описание относится к текущей локальной демонстрации. При размещении сайта в интернете команда должна обновить сведения о доступных функциях, ответственном лице и обработке данных.
